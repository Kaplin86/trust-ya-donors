# Trust Ya' Donors!
Trust Ya Donors! is a game where you analyze relics using books found within your office. The goal is to be the most accurate in determining whether a relic is real or fake.

## Info
- Made in Godot 4.7
- Made for [Brackeys Game Jam 2026.2](https://itch.io/jam/brackeys-16/rate/4952620)
- Features 8 unique relics and 32+ fake variants for those relics (as of commit 20 / game jam build)
- Contains a incredibly scuffed museum map
- User prompt to hide the museum to save resources (on web builds only)

## Controls
WASD / Arrow keys to move.
E to select a relic
Mouse to move a relic once it is selected.

## Development
- For models, I use [Blockbench](https://blockbench.net/), and you can find the models for certain assets in their respective .bbmodel files.
- To setup a dev build of the project, clone the repo and click Import in godot 4.7, then select the repo.
